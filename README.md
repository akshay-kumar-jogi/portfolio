# Akshay Kumar Jogi — Portfolio

Personal portfolio website for Akshay Kumar Jogi, a BCA student in Belagavi building foundations in software development.

## Included sections

- Introduction and personal story
- Selected work: Spotify interface clone and Figma UI/UX design learning project
- Technical foundations: JavaScript, Java, and data structures & algorithms
- Learning beyond the screen: Rotaract leadership, ideathon, and anchoring experiences
- Professional contact links

## Project files

- `index.html` — portfolio content and SEO metadata
- `styles.css` — visual design and responsive layout
- `script.js` — navigation, scroll reveals, and ticker animation
- `assets/` — portfolio images
- `robots.txt` — search-engine crawl rules

## Updating the portfolio

Update `index.html` when adding projects, learning milestones, or professional links. Keep project descriptions accurate and distinguish tools used in completed work from technologies currently being learned.

## Publishing

Deploy the folder to Vercel. Once the final Vercel URL is available, add it as the canonical URL and create a sitemap before submitting the portfolio to Google Search Console.
